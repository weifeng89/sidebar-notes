# Security policy

Sidebar Notes is a local macOS application. Its library, CLI, SSH remote command, file watcher, and file import paths are part of the security boundary.

## Reporting a vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/weifeng89/sidebar-notes/security/advisories/new) for suspected vulnerabilities. Include the affected version or commit, reproduction steps, and impact. Do not include note contents, credentials, or other personal data in a report.

The upstream Stik security policy is preserved at [docs/upstream/stik-SECURITY.md](docs/upstream/stik-SECURITY.md) for historical reference; its contact details and product statements do not apply to this fork.
