# Sidebar Notes

Sidebar Notes keeps working knowledge and delivery files in a local, visible library.

## Language

**Library**:
The user-selected root directory that owns Sidebar Notes categories, projects, notes, and artifacts.
_Avoid_: vault, database

**Category**:
One of the three top-level library directories: Prompt, Notes, or Docs.

**Project**:
A real subdirectory under a category that groups related notes and artifacts. Nested subdirectories remain part of that project tree.

**Note**:
A user-editable Markdown file in the library. Its text and filename remain readable outside the app.

**Artifact**:
A delivery file kept in its original format in a project, such as a PDF, image, or spreadsheet. A Markdown description may sit beside it.

**Source association**:
A confirmed link between an artifact and the chat or work that produced it. Suggested associations are not confirmed associations.

**Conflict copy**:
A preserved version of a note created when an external edit overlaps an unsaved in-app draft. The user chooses how to reconcile the versions.
